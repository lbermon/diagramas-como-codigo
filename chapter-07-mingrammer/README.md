# Chapter 7 – Mingrammer

This directory contains the Mingrammer source code presented in **Chapter 7** of the book *Diagramas como Código en Ingeniería de Software*.

The examples illustrate the specification of cloud architecture diagrams using the Python-based Mingrammer library, including:

- Cloud architecture diagrams
- Multi-tier applications
- Network infrastructures
- Containerized environments
- Multi-cloud deployments

Each source file can be executed using the Mingrammer Diagrams library to reproduce the figures presented in the book.

The examples are intended for educational purposes and can be freely adapted to support software architecture documentation and cloud infrastructure modeling projects.
