# Chapter 11 – Case Studies

This directory contains the source code of the case studies presented in **Chapter 11** of the book *Diagramas como Código en Ingeniería de Software*.

The examples demonstrate the practical application of Diagram-as-Code techniques in realistic software engineering scenarios. They illustrate how the same system can be modeled using different textual languages and tools, highlighting the strengths and characteristics of each approach.

The case studies include examples developed with:

- PlantUML
- Structurizr DSL
- Mermaid

The examples are intended for educational purposes and can be adapted to support software architecture documentation and software engineering projects.
