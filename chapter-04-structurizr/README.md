# Chapter 4 – Structurizr DSL

This directory contains the Structurizr DSL source code presented in **Chapter 4** of the book *Diagramas como Código en Ingeniería de Software*.

The examples illustrate the specification of software architecture models based on the C4 Model using Structurizr DSL, including:

- System Context diagrams
- Container diagrams
- Component diagrams
- Dynamic diagrams
- Deployment diagrams

Each source file can be rendered using Structurizr Lite or the Structurizr CLI to reproduce the figures presented in the book.
