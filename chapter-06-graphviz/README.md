# Chapter 6 – Graphviz

This directory contains the Graphviz source code presented in **Chapter 6** of the book *Diagramas como Código en Ingeniería de Software*.

The examples illustrate the specification of graphs and diagrams using the DOT language, including:

- Directed graphs
- Undirected graphs
- Hierarchical diagrams
- Entity-Relationship diagrams
- Finite-state machines

Each source file can be rendered using Graphviz-compatible tools to reproduce the figures presented in the book.
