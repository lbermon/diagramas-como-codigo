# Chapter 10 – Artificial Intelligence

This directory contains the source code and examples presented in **Chapter 10** of the book *Diagramas como Código en Ingeniería de Software*.

The examples illustrate how Generative Artificial Intelligence can assist in the creation, transformation and documentation of diagrams as code using different tools and textual languages.

The materials include AI-generated examples for:

- PlantUML
- Structurizr DSL
- Mermaid
- Graphviz

The examples are intended to demonstrate AI-assisted diagram generation and may be adapted to support software engineering documentation and architecture modeling projects.
