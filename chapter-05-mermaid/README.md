# Chapter 5 – Mermaid

This directory contains the Mermaid source code presented in **Chapter 5** of the book *Diagramas como Código en Ingeniería de Software*.

The examples illustrate the specification of diagrams using Mermaid, including:

- Flowcharts
- Sequence diagrams
- Class diagrams
- State diagrams
- Entity-Relationship diagrams
- Gantt charts
- Git graphs

Each source file can be rendered using Mermaid-compatible editors and platforms to reproduce the figures presented in the book.
